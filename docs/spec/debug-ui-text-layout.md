# Debug UI 文字配置仕様

## 対象

Runtime IMGUI／uGUI／UI Toolkit、EditorのCommand・Setting・Inspector・履歴・Display設定・診断、およびHUD／Overlayの文字。配置の意味を共通化し、renderer既定styleへ任せない。

## 揃える基準を区別する

1. **ブロック配置:** 項目名を入力欄の左（Editorでは上）に置く、説明をその下に置く、といった部品間の関係。
2. **水平揃え:** 各部品の内側で左／中央／右のどこから文字を置くか。
3. **垂直揃え:** 各部品の内側で上／中央／下のどこに文字行を置くか。

「項目名は上段」と「入力文字は上揃え」は別である。入力欄を48高へ広げたときに文字だけ上へ残る状態は不適合。

**原則: 単一行の操作部品は縦中央。文章を読む複数行の領域は左上。下揃えを標準とする部品は設けない。**

縦中央の対象はフォントの行ボックス（ascender／descenderを含む組版上の行）であり、文字列ごとに異なる黒い画素の外接矩形ではない。`111`から`gj`への変更でbaselineを動かさない。

## 部品ごとの配置

| 部品 | 水平 | 垂直 | 相対位置・折返し |
| --- | --- | --- | --- |
| 数値／一行文字列／検索入力 | 左 | 中央 | 入力内容・placeholderとも同じ位置。数値も右寄せにしない。長い値は欄内移動または全文編集へ |
| readonlyの一行値／Missing／未対応型 | 左 | 中央 | 編集可能な入力と同じ行高・文字開始位置。readonlyになっても上へ寄せない |
| 一般の項目名 | 左 | 上 | Runtimeは行幅40%の左列に置き、2行まで折り返す。1行目を値の行の縦中央に合わせる。3行以上になる場合と行幅280未満では入力欄の直上へ置く。Editorは入力欄の直上。直上では必要な高さに全文折返し。ASCII spaceを含まない連続文もCJK文字境界で折り返す。名称内の最終行から入力まで同じ間隔 |
| 項目名の注記（`Immediate`、`Read only`等） | 左 | 上 | 項目名の下の小さな札。大文字で表示し、項目名の文字列へ連結しない |
| X／Y／Z／W、R／G／B／A | 左 | 中央 | 入力の左側の成分列。入力行の中心と一致。複数成分は縦並び |
| RuntimeのBool switch | 右 | 中央 | 値の列の右端・縦中央。文字を持たず、On／Offはつまみの位置と色で示す |
| EditorのCheckbox／Toggleの短い文字 | 左 | 中央 | チェック図形も同じ行の縦中央。図形の下端へ文字を揃えない |
| Boolの長い項目名 | 左 | 上 | 他の項目と同じ規則で項目名の列または入力の直上に置く。長文を固定高Toggle行へ押し込まない |
| Sliderの数値欄 | 左 | 中央 | 通常数値欄と同じ。Sliderのtrack／thumbはその操作行の縦中央 |
| Sliderの端点値など一行注記 | 左端は左、右端は右 | 中央 | それぞれの注記領域内で中央。trackより上端に張り付けない |
| 対象／Enum／プリセットの選択値 | 左 | 中央 | 一行の選択ボタン内。選択ページを開くものは右端に›を縦中央で置く。Runtimeでその場で前後するEnumは‹ 値 ›とし、値は‹と›の間で中央。長い選択結果は省略可、選択一覧で全文を読む |
| 実行／適用／取消／戻る等の操作ボタン | 中央 | 中央 | 文字ブロックをボタン内の中央に置く。通常は一行。収まらない場合は幅調整・配置切替を使う |
| エラー「!」／閉じる「×」／戻る記号／全文編集「…」 | 中央 | 中央 | 記号の専用枠内で中央。通常ボタンの余白を流用して片寄らせない |
| Home・Command・Setting・参照・履歴などの選択行 | 左 | 中央 | 名前が一行なら行の縦中央。複数行の候補は各行左寄せの文字ブロック全体を行の中央へ。★などの印は名前の前 |
| 名前＋補助情報を持つ候補行 | 左 | 中央（全体） | 名前が上、path／時刻等が下。二つを一つのブロックとして中央へ。左右別々の縦基準にしない |
| 選択行の件数・結果と下の階層を示す› | 右 | 中央 | 行の右端。›を最も右に置き、件数・結果はその左。名前のブロックとは別に行の縦中央 |
| TreeViewの一行・折りたたみ記号 | 左 | 中央 | 深さによるindentだけを加える。文字・展開記号・選択背景の行中心を合わせる |
| Editor機能タブ・下部タブ・狭幅切替タブ | 中央 | 中央 | タブ内中央。選択状態でpaddingやbaselineを変更しない |
| 画面headerのタイトル | 左 | 中央（全体） | タイトル領域内。menu内の位置（小さい文字）が上、ページ名（太字）が下。そのブロック全体をheader内中央へ。位置が無いページはページ名だけを中央へ |
| セクション見出し・グループ名 | 左 | 上 | 後続項目の上。自然な行高で必要な行数を取る。大きな空の固定枠へ上寄せしない |
| フィールドの補助説明・範囲 | 左 | 上 | 説明対象の入力／操作の直下。常設文の高さはvalidation状態で変えない。Runtimeの方式注記は項目名の注記の行に従う |
| footerの状態文／適用中プリセット名 | 左 | 中央（一行枠内） | 操作行の上に専用行を置く場合、その行内で中央。選択ボタン内に名前を表示する場合は選択値の規則 |
| 確認画面の説明／エラー詳細本文／診断本文 | 左 | 上 | 本文領域のpadding内の左上から読み進める。短文でも巨大な本文領域の縦中央へ置かない |
| 前回結果／JSON／stack trace／複数行readonly値 | 左 | 上 | 上から表示して必要時scroll。結果名や状態badgeが一行枠ならその枠では縦中央 |
| 複数行TextArea／全文編集 | 左 | 上 | 固定高の編集領域の左上。先頭行にも上paddingを確保し、枠線へ接触させない |
| Watchの名前・値の二段表示 | 左 | 中央（全体） | 名前が上、値が下。ブロック全体を行中央へ。長い値は折返し用の必要高を取る |
| 一覧の「該当なし」など空状態 | 左 | 上 | 本文の開始位置。ボタンや入力欄に見える中央配置を追加しない |
| HUD／Overlayの一行ラベル | 左 | 中央 | 固定の表示行内で中央。複数行の表示blockは左上から行を積む |

テーブルを使用する画面では、列headerは左・縦中央、一行セルも左・縦中央、複数行セルは左・上。表の数値だけを暗黙に右寄せする例外は設けない。

## 寸法・余白

数値はscale適用前の参照UI単位であり、物理画素とは区別する。文字サイズを変えずに行高だけを28／36／44／48へ変更できる。

- 一行入力の文字領域は左右6、上下は対称に最低4の内側余白を確保し、残り領域で縦中央に配置する。borderは別途内側領域から差し引く。
- 一行の縦中央は、内側領域の中心と行ボックスの中心の差を参照UI単位で1以下（pixel丸めを考慮）とし、行高を変えても維持する。
- 通常ボタンは左右8、上下対称の最低4。記号ボタンは中央配置を優先し、左右で異なる余白を付けない。
- 行高がfontとpaddingの必要高に足りなければ、最小hit高の規則に従って必要高を確保する。文字を上に押し付けたり、上下を切って収めない。
- 項目名を左に置く場合、項目名の列は行幅の40%、値の列との間隔は6。項目名を直上に置く場合、直下の入力との間隔は5。成分行同士の間隔は4。成分ラベル列は36、列間6、「…」列は28（「…」を持つ行だけ）とする。
- 一行の基準行ボックスを18とした例では、28高で上下5、48高で上下15の空間になる（borderなしの説明値）。行高の増加分を下側だけへ加えない。
- 複数行の本文・TextAreaでは上下の余白を維持し、文字は上から積む。余った高さを行間へ均等配分しない。
- 項目名は内容・幅に応じた可変高。入力行は一定高。この二つを合計したfield全体の高さまで一律にする必要はない。

```text
項目名（行幅の40%、    ┌──────────────┬───┐
2行まで折返し）        │   上側の余白 │   │
               ← 6 →   │  123.45      │ ! │ ← 値は左／縦中央、!は水平・垂直中央
                       │   下側の余白 │   │
                       └──────────────┴───┘
補助説明                         ← 入力の下・左上
```

項目名が3行以上になる場合と行幅280未満では、項目名を入力の上へ置き、間隔5で入力を続ける（Editorは常にこの形）。

## 状態が変わっても動かさないもの

Normal／Hover／Focused／Disabled／Readonly／Invalid／Selectedで、font・文字サイズ・alignment・padding・border占有幅・行高・baselineは共通。色や枠の表現だけを変える。太字などに変える場合も文字領域を変えず、名称の折返しが変化しないことを条件とする。

Editorはエラーなしの行もエラー枠を予約する。Runtimeの入力の行はエラー枠を置かず、入力欄の枠を赤くしてエラー文を値の下へ書く（全renderer共通）。いずれもエラー文字やborderの追加で入力の文字開始位置をずらさない。TextFieldからreadonly Labelへ替える場合も同じ文字領域を使用する。focus枠は領域の外側に描くか常時予約し、内側文字を押さない。

ボタンを二段に並べるフォールバックでも各ボタン内は中央のまま。エラー詳細を別ページへ替えても本文は左上、戻るボタンは中央のまま。

## renderer別の配置指定

IMGUIでは一行値・成分ラベル・選択行に`MiddleLeft`、操作／記号ボタンに`MiddleCenter`、文章・TextAreaに`UpperLeft`相当の配置を明示する。GUIStyleの既定alignmentや他のSkinからの継承だけで決定しない。styleはcacheし、正常／error／disabled間で文字geometryを共通化する。

複数行候補と二段headerは、文字ブロックの必要高を先に求め、親領域の中央へ配置した子領域に左上揃えで描く。項目名の折返し測定幅からscrollbar・padding・エラー列など実際に占有する領域を除外する。

uGUI／UI Toolkitも同じ内側領域・line box基準を使う。font metricsの差は認めるが、IMGUIだけ文字が行上端へ寄る状態は許容しない。font ascent補正はfont／style単位で固定し、表示中の文字列ごとに補正値を変更しない。

## World図形との位置関係

HUD／Overlayの行内配置と、図形の上・下・中心に文字を取り付けるanchorは別の仕様である。`DrawLabel`はworld anchor引数を持たず、本書はWorld anchorを定めない。
